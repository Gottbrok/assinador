# Medições da F0

Cada medição tem data, equipamento e quem mediu. O que não foi medido fica marcado como pendente,
nunca presumido.

## Equipamento

- Ubuntu 24.04, x86_64, gcc 13.3, Go 1.27.1.
- Middleware SafeSign (A.E.T. Europe) em `/usr/lib/libaetpkss.so.3`, Cryptoki 2.20, biblioteca 3.0.
- OpenSC 0.25 em `/usr/lib/x86_64-linux-gnu/opensc-pkcs11.so`, Cryptoki 2.20.
- Serviço `pcscd` ativo; socket em `/run/pcscd/pcscd.comm`.
- Navegadores: Chrome (pacote .deb), Chromium 153 em Snap, Firefox 155 em Snap.
- Cartão: Certisign em leitora USB (a conectar).

## Medido

**2026-09-25 · Claude, sem cartão na leitora**

- Os dois módulos carregam e inicializam pela ferramenta `ferramentas/prova` (`C_Initialize`,
  `C_GetInfo`); sem leitora conectada, os dois respondem zero slots com token presente, sem erro.
- **Achado para a F2a:** o `Login` do `github.com/miekg/pkcs11` v1.1.2 recebe o PIN como `string`,
  copia para o C com `C.CString` e libera com `C.free` SEM zerar (`pkcs11.go`, função `Login`). Uma
  cópia do PIN sobra na memória liberada do processo, contra a regra 2 do `CLAUDE.md`. Com PIN vazio,
  o pacote passa `NULL`, o que está certo para `CKF_PROTECTED_AUTHENTICATION_PATH`. O programa de
  verdade precisa de um invólucro próprio de `C_Login`: aloca com `C.malloc`, copia, chama, zera com
  escrita volátil e só então libera. A ferramenta de prova usa o pacote como está e zera a sua cópia
  em Go (a string aponta para os mesmos bytes do slice).

## Pendente (precisa do cartão e do Cairo)

- **(a)** O SafeSign declara `CKF_PROTECTED_AUTHENTICATION_PATH` para este cartão, exige PIN pelo
  `C_Login` ou abre diálogo próprio? `prova listar --modulo /usr/lib/libaetpkss.so.3` imprime a flag.
  Também mede se a chave privada é visível antes do login.
- **(b)** O OpenSC enxerga este cartão? `prova listar --modulo /usr/lib/x86_64-linux-gnu/opensc-pkcs11.so`.
- **Assinatura verificada pelo openssl:** `prova assinar` com a `ref` que o `listar` mostrar, digitando o
  PIN no terminal; a ferramenta confere com `crypto/rsa` e imprime o comando do `openssl pkeyutl`.
- **(c)** Native messaging no Firefox em Snap e no Chromium em Snap (e no Chrome .deb, como base):
  `ferramentas/prova-mensagens/instalar.sh`, carregar a extensão de `ferramentas/prova-mensagens/extensao`
  e clicar em "Olá" e "Listar". O que interessa não é só o host responder: é o host lançado pelo
  navegador alcançar o `pcscd` e o SafeSign (a resposta de "Listar" diz, por módulo).
- **(d) e (e)**, Windows: dependem da máquina Windows com leitora. Sem ela, passam para a F6a.
